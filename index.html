📖 九宫井字棋 规则

1. 术语定义

  • 大棋盘：一个 3×3 的九宫格，每个格子称为“大格”。
  • 小棋盘：每个大格内包含一个独立的 3×3 井字棋棋盘。
  • 小方格：小棋盘内的落子位置，行、列编号均为 1～3。
  • 坐标映射：小棋盘内第 r 行第 c 列，对应大棋盘第 r 行第 c 列的大格。
  • 大格状态：
    • 开放：尚未被赢下且有空格。
    • X赢：X 达成三连。
    • O赢：O 达成三连。
    • 障碍：填满但无人获胜。
  • 不开放：指 X赢、O赢 或 障碍。

2. 游戏目标

先在大棋盘上连成横、竖或斜三线的一方获胜。

3. 基本流程

  1. X 先手。
  2. 第一手：X 可在任意开放小棋盘落子。
  3. 双方轮流落子。
  4. 落子后立即结算小棋盘、检查大棋盘胜负、检查平局。
  5. 若未结束，根据第4、5条确定对手落点大格。

4. 落子位置决定下一手

  • 若当前玩家在小棋盘内局部位置为 (r,c)，对手下一手必须前往大棋盘第 r 行第 c 列。
  • 若该指定大格开放，对手必须在该大格落子。
  • 若该指定大格不开放，按第5条回溯。

4.1 后手第一手特例

O 的第二手不受限制，可自由落子，但其局部位置仍用于指定 X 的下一手。

5. 回溯规则

  1. 设触发回溯的上一手为 A。
  2. 忽略 A，从 A 的前一手开始倒序检查历史落子。
  3. 取每手局部位置 (r,c)，检查大棋盘第 r 行第 c 列是否开放。
  4. 找到第一个开放大格后必须在该大格落子。
  5. 若全部检查完仍无开放大格，可任选开放小棋盘。

补充说明：历史落子包括从第一手到上一手。自由选择落子同样参与回溯检查。

6. 小棋盘结算

每次落子后：若出现三连则该方赢下；否则若已填满则变为障碍；否则保持开放。

7. 大棋盘胜负判定

只有被赢下的小棋盘才能作为大格标记。

8. 平局与提前结束

所有大格均不开放且无三连，或双方均不可能形成三连。

8.1 “不可能形成三连”的判定

对某方 P，若8条线全部被对方大格或障碍阻断，则 P 不可能获胜。
